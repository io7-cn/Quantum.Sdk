# Quantum.Plugin.Abstraction

Public .NET plugin contracts for Quantum Desktop. Target `net10.0` and pin a package version compatible with your host. The package includes the plugin lifecycle, identity, request, notification and mobile page declaration contracts, plus a Roslyn analyzer.
